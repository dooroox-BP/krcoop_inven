# 인천광역시협동조합협의회 결산 입력 프로그램 (MVP)

`cooperative-excel-accounting-app`

Excel 파일(.xlsx)을 데이터 저장소로 사용하는 협동조합 결산 입력·보고 프로그램입니다.
사용자는 엑셀 파일을 직접 열지 않고, **웹 화면(Streamlit)** 에서 거래를 입력합니다.
프로그램이 입력 내용을 엑셀 파일에 저장하고, **수입결산 / 지출결산 / 차입금현황 /
간이대차대조표 / 검증표 / 총회보고서**를 자동으로 갱신합니다.

---

## 1. 프로젝트 개요

- **목적**: 협의회 결산(수입·지출·차입금·자산)을 표준 계정과목으로 입력하고,
  결산 보고서와 검증표를 자동 생성한다.
- **저장소**: 별도 데이터베이스 없이 **Excel 파일 한 개**를 DB처럼 사용한다.
- **클라우드 미사용**: Google Sheets·외부 클라우드를 사용하지 않는다. 모두 로컬에서 동작한다.
- **핵심 회계 기준**
  - 차입금은 수입이 아니다 → **차입유입/차입상환은 수입·지출 합계에서 제외**하고
    차입금현황으로만 관리한다.
  - 자산증가/자산감소는 **간이대차대조표(자산)** 에만 반영한다.
  - 자금조정은 **현금잔액 검증**에만 반영한다.
  - 삭제 거래(상태=삭제)는 **모든 집계에서 제외**한다(soft delete).

### 기술 스택
Python · Streamlit · openpyxl · pandas · pathlib · datetime (표준 라이브러리)

## 2. 설치 방법

```bash
# 프로젝트 폴더로 이동
cd cooperative-excel-accounting-app

# 가상환경 생성
python -m venv .venv

# 가상환경 활성화
#  Windows
.venv\Scripts\activate
#  Mac / Linux
source .venv/bin/activate

# 의존성 설치
pip install -r requirements.txt
```

```bash

실행 후 브라우저에서 열리는 주소(기본 `http://localhost:8501`)로 접속합니다.

> 처음 실행 시 데이터 파일이 없다면 아래 명령으로 **2025년 샘플 데이터**를 생성할 수 있습니다.

## 4. 엑셀 파일 위치

```
cooperative-excel-accounting-app/data/협의회_결산_입력프로그램_엑셀양식.xlsx

이 파일 하나가 데이터베이스 역할을 합니다. 포함 시트:

| 시트 | 설명 |
|------|------|
| 사용안내 | 사용 방법 안내 |
| 거래입력대장 | 모든 거래 원장(입력 데이터) |
| 계정과목 | 입출구분·대분류·소분류 목록 |
| 기초잔액 | 연도별 기초 현금·차입금·미수금·선급금 |
| 자산관리 | 자산증가/감소 거래 정리 |
| 수입결산 | 수입 대분류·소분류별 합계 |
| 지출결산 | 지출 대분류·소분류별 합계 |
| 차입금현황 | 기초·유입·상환·기말 차입금 |
| 간이대차대조표 | 자산 / 부채·자본 |
| 검증표 | 8개 검증 항목 결과 |
| 총회보고서 | 총회 상정용 결산보고 |
| 목록 | 입출구분·사업구분·결제수단 등 참조 목록 |

## 5. 사용 순서

1. **엑셀 파일을 닫습니다.** (열려 있으면 저장이 충돌합니다 — 9번 항목 참고)
2. `streamlit run app.py` 로 프로그램을 실행합니다.
3. 사이드바 메뉴에서 작업을 선택합니다.
   1. 대시보드
   2. 거래 입력
   3. 거래 조회·수정
   4. 수입결산
   5. 지출결산
   6. 차입금현황
   7. 간이대차대조표
   8. 검증표
   9. 총회보고서
   10. 설정
4. **거래 입력** 화면에서 거래를 입력하고 저장합니다.
5. 저장 시 거래입력대장에 기록되고, 결산·보고서·검증표가 **자동 갱신**되며, **백업이 생성**됩니다.
6. **검증표** 화면에서 종합 검증상태가 `정상`인지 확인합니다.
7. **총회보고서** 화면에서 결산보고 미리보기를 확인합니다.

---

## 6. 거래 입력 방법

**거래 입력** 화면에서 다음을 입력합니다.

- 회계연도, 거래일자, 입출구분, 대분류, 소분류, 금액 → **필수**
- 거래처, 사업구분, 결제수단, 증빙여부, 증빙링크, 비고, 입력자 → 선택

입력 규칙:

- **입출구분 → 대분류 → 소분류** 순으로 선택하면, 앞 선택에 맞는 항목만 표시됩니다.
- **금액은 0보다 커야** 합니다.
- 거래ID는 자동 생성됩니다 → 형식 `TX-YYYYMMDD-0001`
- 저장 전 입력값이 자동 검증됩니다(필수값·금액·계정과목).

**수정/삭제**는 **거래 조회·수정** 화면에서 합니다.
삭제는 실제 행을 지우지 않고 **상태를 '삭제'로 변경**(soft delete)하며, 집계에서 제외됩니다.

---

## 7. 보고서 갱신 방법

- 거래를 **저장/수정/삭제**하면 해당 연도의 모든 보고서·검증표가 자동으로 다시 계산됩니다.
- 각 보고서 화면(수입결산·지출결산·차입금현황·간이대차대조표·검증표·총회보고서)에서
  **"시트 갱신"** 버튼을 누르면 해당 시트를 다시 계산하여 엑셀에 기록합니다.
- **설정 → "모든 보고서/검증표 재생성"** 으로 전체를 한 번에 갱신할 수 있습니다.

---

## 8. 백업 파일 위치

파일을 변경(거래 저장/수정/삭제, 보고서 갱신)하기 **전에** 항상 백업이 생성됩니다.

```
cooperative-excel-accounting-app/backups/
```

백업 파일명 형식:

```
협의회_결산_입력프로그램_엑셀양식_YYYYMMDD_HHMMSS.xlsx
```

최근 백업 목록은 **설정** 화면에서 확인할 수 있습니다.

## 9. ⚠️ 주의사항 (반드시 확인)

> **프로그램 실행 중에는 데이터 엑셀 파일을 열어두지 마세요.**
>
> 엑셀 파일(`data/협의회_결산_입력프로그램_엑셀양식.xlsx`)을 Excel에서 **열어둔 상태**로
> 프로그램이 저장을 시도하면 **파일 잠금/저장 충돌**이 발생하여 데이터가 손상되거나
> 저장이 실패할 수 있습니다.
>
> - 프로그램을 실행하기 전에 엑셀 파일을 **닫아** 주세요.
> - 결과를 엑셀로 확인하려면, 프로그램에서 저장을 마친 뒤 파일을 여세요.

## 10. 2025년 검증 기준

샘플 데이터(2025년) 기준 결과는 다음과 같아야 합니다.

| 항목 | 금액 |
|------|-----:|
| 수입합계 | 54,942,020원 |
| 지출합계 | 43,656,222원 |
| 당기수지차 | 11,285,798원 |
| 기초 현금·예금 | 8,623,440원 |
| 차입금 유입 | 9,000,000원 |
| 차입금 상환 | 15,000,000원 |
| 기말 현금·예금 | 13,909,238원 |
| 차입금 잔액 | 9,000,000원 |
| 미수금 | 3,100,000원 |
| 자산합계 | 17,009,238원 |
| 부채·자본합계 | 17,009,238원 |
| 검증상태 | **정상** |

계산식:

```
당기수지차 = 54,942,020 − 43,656,222 = 11,285,798
기말현금  = 8,623,440 + 54,942,020 − 43,656,222 + 9,000,000 − 15,000,000 = 13,909,238
자산합계  = 13,909,238(현금) + 1,900,000(사업미수금) + 1,200,000(활성화사업 정산 미수금) = 17,009,238
부채·자본 = 9,000,000(단기차입금) + 8,009,238(순자산) = 17,009,238
```
